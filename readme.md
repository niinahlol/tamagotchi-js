# 👾 Tamagotchi JS

Um Tamagotchi simples desenvolvido durante meus estudos de JavaScript no curso de Programação Front-end do SENAI.

O projeto começou como um exercício para praticar `button onclick` e `function` e foi evoluindo conforme novos conceitos foram aplicados.

## 🎮 Funcionalidades

- Escolha do nome do Tamagotchi
- Sistema de fome
- Sistema de felicidade
- Sistema de energia
- Atributos diminuem com o tempo
- Botões para alimentar, brincar e dormir
- Barras de status dinâmicas
- Mudança de cores conforme o estado
- Expressões diferentes para o pet
- Mensagens baseadas nas necessidades do Tamagotchi

## 📚 Conceitos praticados

- HTML
- CSS
- JavaScript
- `onclick`
- Funções
- Parâmetros
- `if`, `else if` e `else`
- Operadores lógicos
- `setInterval()`
- Manipulação do DOM
- `getElementById()`
- `textContent`
- `.value`
- Booleanos

## 💜 Sobre o projeto

Este é um projeto de estudo e ainda está em desenvolvimento.

O código JavaScript possui comentários explicando partes da lógica para facilitar o entendimento de outros estudantes iniciantes.

Os sprites do Tamagotchi também foram criados por mim em pixel art.
